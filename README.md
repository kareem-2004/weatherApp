# React Native Weather App 

A beginner-friendly weather application built with React Native and Expo.

## Features

- Search for any city
- Get current weather information
- Display temperature
- Display weather condition
- Display humidity
- Display feels-like temperature
- Display wind speed
- Loading and error handling

## Technologies

- React Native
- Expo
- JavaScript
- REST API
- Fetch API

## API

This project uses the Open-Meteo API for weather and geocoding data.
